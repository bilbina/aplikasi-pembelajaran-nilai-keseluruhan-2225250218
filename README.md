# Toko Unit - Nilai Keseluruhan, Nilai Per Unit, dan Nilai Sebagian

Aplikasi web (React + Vite + Supabase) untuk membantu siswa SMP belajar harga per unit dengan beban kognitif rendah.

Dokumen perencanaan: `CLAUDE.md`, `PRD.md`, `DESAIN.md`.

## Menjalankan
```
npm install
npm run dev
```
Isi `.env` dengan `VITE_SUPABASE_URL` dan `VITE_SUPABASE_ANON_KEY`.
